# LLM Pipeline Explorer

An interactive web visualization exploring how Large Language Models process prompts through tokenization, embeddings, transformer attention/MLP layers, and next-token sampling.

## Files

- `index.html` — Complete self-contained interactive web application (HTML, CSS, and JavaScript).

## Running Locally

Open `index.html` directly in any modern browser, or serve the directory over HTTP:

```bash
python3 -m http.server 8080
```
